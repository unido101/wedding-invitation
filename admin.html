Admin Undangan

Atur isi undangan dan buat link tamu. Draf tersimpan di browser ini, dan undangan baru berubah setelah file config.js di repo diganti.

Amplop digital

Cara menerbitkan
  1. Isi form, lalu klik Pratinjau untuk melihat hasilnya.
  2. Klik Unduh config.js, lalu ganti file config.js di folder repo.
  3. Commit dan push. Vercel atau GitHub Pages akan memperbarui undangan.
